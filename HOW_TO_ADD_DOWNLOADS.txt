=============================================================================
HOW TO MAKE "DOWNLOAD" BUTTONS WORK IN JAVASCRIPT (NO BACKEND REQUIRED)
=============================================================================

Since this is a front-end only application, you can't just link to a server file to download a report. Instead, you have to use Javascript to generate a "Blob" (a piece of data), convert it into an Object URL, and trick the browser into clicking a hidden download link.

Here is exactly what you need to do to make the three download buttons in your app work.

-----------------------------------------------------------------------------
STEP 1: CREATE A HELPER FUNCTION
-----------------------------------------------------------------------------
First, create a new file named `downloadHelper.js` anywhere in your `src` folder (for example, `src/services/downloadHelper.js`).

Paste this exact code into it:

```javascript
// src/services/downloadHelper.js

export const downloadCSV = (dataArray, filename) => {
  // 1. Convert your array of objects into a CSV string
  if (!dataArray || !dataArray.length) {
    alert("No data to download!");
    return;
  }
  
  const headers = Object.keys(dataArray[0]).join(',');
  const rows = dataArray.map(obj => Object.values(obj).join(',')).join('\n');
  const csvContent = `${headers}\n${rows}`;

  // 2. Create a Blob (Binary Large Object) from the string
  const blob = new Blob([csvContent], { type: 'text/csv;charset=utf-8;' });
  
  // 3. Create a temporary download link
  const link = document.createElement('a');
  const url = URL.createObjectURL(blob);
  
  link.setAttribute('href', url);
  link.setAttribute('download', `${filename}.csv`);
  link.style.visibility = 'hidden';
  
  // 4. Append to body, click it, and remove it
  document.body.appendChild(link);
  link.click();
  document.body.removeChild(link);
};
```

-----------------------------------------------------------------------------
STEP 2: UPDATE DASHBOARD.JSX (The "Download Report" button)
-----------------------------------------------------------------------------
File: `src/pages/Dashboard.jsx`

1. Import the helper at the top of the file:
```javascript
import { downloadCSV } from '../services/downloadHelper';
```

2. Find the button (around Line 22) and update the `onClick`:
```javascript
// CHANGE THIS:
<button className="btn btn-secondary">Download Report</button>

// TO THIS:
<button 
  className="btn btn-secondary" 
  onClick={() => downloadCSV(orders, 'dashboard_orders_report')}
>
  Download Report
</button>
```

-----------------------------------------------------------------------------
STEP 3: UPDATE ORDERS.JSX (The "Export Report" button)
-----------------------------------------------------------------------------
File: `src/pages/Orders.jsx`

1. Import the helper at the top of the file:
```javascript
import { downloadCSV } from '../services/downloadHelper';
```

2. Find the Export button (around Line 62) and update it. Notice we are passing the `filtered` array, so it only downloads what the user searched for!
```javascript
// CHANGE THIS:
<Button className="btn-primary">Export Report</Button>

// TO THIS:
<Button 
  className="btn-primary" 
  onClick={() => downloadCSV(filtered, 'orders_export')}
>
  Export Report
</Button>
```

-----------------------------------------------------------------------------
STEP 4: UPDATE BILLING.JSX (The "Download PDF" button)
-----------------------------------------------------------------------------
File: `src/pages/Billing.jsx`

Generating a real PDF in React usually requires a library like `jspdf`. However, for a hackathon, the easiest and most impressive trick is to just trigger the browser's native print window, which allows the user to "Save as PDF".

Find the Download PDF button (around Line 37 inside the table actions):

```javascript
// CHANGE THIS:
<Button variant="secondary" style={{ padding: '0.375rem 0.75rem' }}>Download PDF</Button>

// TO THIS:
<Button 
  variant="secondary" 
  style={{ padding: '0.375rem 0.75rem' }} 
  onClick={() => window.print()}
>
  Download PDF
</Button>
```

That's it! If you implement these steps, the browser will literally generate and download files straight to the user's hard drive purely using frontend JavaScript.
