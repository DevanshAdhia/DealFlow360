Explanation: "Every time the component renders (like when a user types a letter in the search bar), I run the JavaScript `.filter()` method on the entire customer list to calculate exactly which rows to show."

```javascript
  const s = search.toLowerCase();
```
Explanation: "I immediately convert the user's search query to lowercase. This ensures the search is case-insensitive (e.g., searching for 'acme' will successfully match 'Acme')."

```javascript
  return (c.name || '').toLowerCase().includes(s) || 
         (c.company || '').toLowerCase().includes(s) ||
         (c.email || '').toLowerCase().includes(s);
});
```
Explanation: "This is where the defensive programming happens! If I just wrote `c.name.toLowerCase()`, and a customer record was missing a name in the database, the whole React app would instantly crash with a 'TypeError: undefined is not an object'. 
By writing `(c.name || '')`, I tell JavaScript: 'If the name exists, use it. If it doesn't exist, use an empty string.' Then I check if that string `.includes()` the search query across the name, company, or email fields. This guarantees the application is completely crash-proof against bad data."

```javascript
export const downloadCSV = (dataArray, filename) => {
```
Explanation: "I built a utility function that accepts an array of JSON data (like our list of orders) and a desired filename."

```javascript
  const headers = Object.keys(dataArray[0]).join(',');
  const rows = dataArray.map(obj => Object.values(obj).join(',')).join('\n');
```

Explanation: "Here, I am programmatically converting the JSON objects into a comma-separated string format. First I extract the keys for the header row, then I map over the objects to extract their values."

```javascript

```
Explanation: "This is the crucial step. A `Blob` stands for Binary Large Object. Because we don't have a backend to send us an actual file, I tell the browser to take my CSV string and package it into a raw file object directly in memory."

```javascript
  const url = URL.createObjectURL(blob);
  const link = document.createElement('a');
  link.setAttribute('href', url);
  link.setAttribute('download', `${filename}.csv`);
```
Explanation: "Finally, I generate a temporary, invisible URL pointing to that Blob in memory. I programmatically create an invisible `<a>` (anchor) tag, attach the URL to it, and force a click event (`link.click()`). The browser sees the `download` attribute and instantly downloads the file to the user's hard drive."
