LAYER 7: STATE FLOW DIAGRAM
=============================================================================

How data flows when an admin adds a new Customer:

  User clicks "+ Add Customer"
          │
          ▼
  handleOpenAdd() called
  setModalItem({ blank customer object })
          │
          ▼
  Modal renders (isOpen = true)
  User fills form: name, company, email, tier, credit limit
          │
          ▼
  User clicks "Save Customer"
  handleSaveModal() called
          │
          ├── Validation: if(!name) → toast.error, return
          │
          ▼
  isNew = !modalItem.id → TRUE (no id on blank object)
  entityToSave = { ...modalItem, id: 'c_' + Date.now() }
          │
          ▼
  saveEntity('df_customers', entityToSave, true)
  ├── reads current array from localStorage
  ├── creates new array: [...existing, newCustomer]
  └── writes new array back to localStorage
          │
          ▼
  setCustomers(updated)  → React re-renders
  setModalItem(null)     → Modal closes
  toast.success("Customer added!")
          │
          ▼
  DataTable re-renders with new customer in the list
  KPI metric card "Total Accounts" increments by 1

LAYER 8: THE EXPORT ENGINE
=============================================================================

File: src/services/downloadHelper.js

In the full architecture, file exports would come from a backend PDF service.
We implemented this entirely in the browser:

┌──────────────────────────────────────────────────────────────────┐
│                      downloadHelper.js                           │
│                                                                  │
│  Step 1: Convert JS array → CSV string                          │
│          Object.keys(data[0]).join(',')   → header row          │
│          data.map(r => Object.values(r).join(','))  → rows      │
│                                                                  │
│  Step 2: Wrap in a Blob (binary file object in memory)          │
│          new Blob([csvString], { type: 'text/csv' })            │
│                                                                  │
│  Step 3: Create temporary URL pointing to Blob                  │
│          URL.createObjectURL(blob)                               │
│                                                                  │
│  Step 4: Create invisible <a> tag, set download attribute       │
│          link.setAttribute('download', 'filename.csv')          │
│                                                                  │
│  Step 5: Programmatically click the link                        │
│          link.click() → Browser downloads the file              │
│                                                                  │
│  Step 6: Remove the invisible link from DOM                     │
│          document.body.removeChild(link)                        │
│                                                                  │
│  Used in:                                                        │
│  ├── Dashboard.jsx  → Download Orders Report (CSV)              │
│  └── Orders.jsx     → Export Filtered Orders (CSV)             │
│  Billing.jsx uses window.print() → Save as PDF via browser     │
└──────────────────────────────────────────────────────────────────┘
